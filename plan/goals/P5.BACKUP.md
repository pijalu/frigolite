   parity: canonical DefaultHeader into pager.header AND page-1 Data[:100],
   empty schema leaf, numPages=1, file truncated to exactly one page,
   immediate Flush).
2. **frigolite.Open materialized 0-byte files** (R11/T11 hole): the
   unconditional open-time Flush wrote the Init-time schema page into any

   SQLite stores NULL in the record for the rowid-alias column; substitution

   Fix: unconditional IPK rowid fill in buildRowMap and applyStructRowAffinity.
4. **setDestPgsz scope**: empty FILE destinations now adopt the source page
