### UCL tranche

- `testdata/stmtbindconformance/transcript.jsonl` — oracle C-API transcript
  generated by `tools/oracle_c/stmtbind_oracle.c` (scratch C program over the
  system SQLite; regenerate per the README). Covers prepare rc/tail,
  parameter count/name/index, bind RANGE/MISUSE errors, typeof preservation
  for typed binds, embedded-NUL text binds, clear_bindings, double-step
  MISUSE, and close-with-unfinalized BUSY.
- `TestStmtBindConformance` replays the transcript through frigolite's Stmt
  API. Documented normalizations: MAX_VARIABLE_NUMBER 500000 (oracle build)
  → 32766 (SQLite post-3.32 default, same constant the TCL harness emits);
  VDBE state-text quirks ("not an error" / "no more rows available" /
  "another row available") are not asserted.

### Engine (frigolite / internal/exec / internal/sql)

- `internal/exec/params.go` — resolve.c-faithful parameter index assignment
  (`CollectParameterNames`): bare `?`, `?NNN` with gap-fill, named dedup on
  case-folded token text, `:NNN` treated as numbered (sqlite3ExprAssignVarNumber).
- `Engine.Prepare` rejects `?0` / `?NNN > MaxVariableNumber (32766)` at
  prepare time with SQLite's message text.
- Lexer: `scanDollarName` continues only on `::` (tokenize.c CC_DOLLAR), so
  `$abc:123` splits into `$abc` + `:123` → `near ":123": syntax error`;
  `$abc(123` unterminated → `unrecognized token: "$abc(123"` (bind-1.10/1.11,
  bind-11.1). `readAtParam` takes a plain IdChar run (CC_VARALPHA).
- `Stmt`: `BindParameterCount/Name/Index`; SQLITE_RANGE out-of-range binds
  ("column index out of range"); vmDone/vmPoisoned misuse states (step after
  DONE → "no more rows available", bind after DONE → "bad parameter or other
  API misuse"; neither poisons finalize); `BindNamed` routes through slots;
  `renderBoundSQL` rewritten over the SQL tokenizer with paramNames slot
  resolution (`:NNN` numbered, bare `?` continues from max slot); typed
  literal rendering preserves REAL (NaN→NULL).
- `FirePreupdate` applies column affinities to old/new values (bind2 IntReal).

### Transpiler (tools/tcl2go)

- Per-file shared preparedState singleton: a prepare inside one do_test body
  is visible to later bodies (bind.test prepares in its first body).
- Runtime VM emission for Stmt-VM files (`stmtVMTestFiles`): prepare stores a
  real *Stmt (`tclPrepareStmt`, honoring nByte truncation and executing
  queries at prepare time so compile errors surface — frigolite resolves
  columns lazily); typed runtime binds (`tclBindStmt`, octal escapes +
  nlen truncation + blob10/static semantics from test1.c test_bind);
  cursor-based stepping (`tclStepStmt` ROW→DONE, reset/rebind restarts);
  reset/finalize/clear_bindings result codes; parameter-metadata and
  column_* value handlers; `sqlite_step` proc wrapper; x_coalesce
  registration via `sqlite3_create_function`; bind2 preupdate-hook closure
  transpiled from the named proc.
- Non-Stmt-VM files keep their historical emissions byte-for-byte (gated by
  `stmtVMEnabled()`), so the wider corpus is untouched.
- errmsg on a closed failed-open connection = "bad parameter or other API
  misuse" (capi3c-3.6.2-misuse, pre-existing failure at goal start).
- tclRenderCell: TCL-style exponential doubles ("1e+300", not "1.0e+300").
