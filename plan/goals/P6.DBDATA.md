# P6.DBDATA — `sqlite_dbdata` virtual table (no NoopModule)

## Objective
Implement the SQLite `sqlite_dbdata` virtual table module (src/dbdata.c) in
frigolite so `dbdata` is no longer registered as `NoopModule`. The module
inspects raw database pages and decodes them into rows:
`(pgno, cell, field, value, header, type, length, leaf)`. It is the read-only
companion to `sqlite_dbpage` (already implemented).

## Context
- `internal/vtab/vtab.go` registers `dbdata` as `&NoopModule{}` (line ~123) and
  `sqlite_dbpage` is already a real module. There is currently **no**
  `sqlite_dbdata` implementation anywhere in the tree (grep-confirmed).
- Depends on the **`vtab.Database` interface** (slice 1 of P6.RTREE): the module
  needs to read raw pages via a `PageSource` (same mechanism dbpage uses) and
  run SQL to discover schema (`sqlite_schema`) for cell decoding.
- Source of truth: `../sqlite/src/dbdata.c`; oracle `/usr/bin/sqlite3`.

## Design (SOLID)
- `internal/vtab/dbdata.go` — `DBDataModule` (constructor takes a
  `PageSourceProvider`, mirroring `NewDBPageModule`), `DBDataVTab`,
  `DBDataCursor`. Columns: `pgno, cell, field, value, header, type, length,
  leaf`. `BestIndex` = full scan. `Open`/`Next` iterate pages, decode the b-tree
  page header, walk cells, decode each record field via the record codec
  (reuse `internal/storage` record decoding).
- Reuse `internal/vtab/dbpage.go`'s `PageSource`/`PageSourceProvider` for raw
  page reads (no new storage code).
- Decode cell pointers + payload overflow chains (use existing page reader).

## Slices
1. Module skeleton: `NewDBDataModule(provider)`, register in
   `internal/exec/engine.go` replacing the `dbdata` Noop. Smoke test:
   `CREATE VIRTUAL TABLE t1 USING sqlite_dbdata` succeeds; columns correct.
2. Page decode: header magic, cell count, cell pointer array; emit one row per
   cell with pgno/cell/leaf. Verify vs oracle on a small db.
3. Field decode: for each cell, decode the record into fields (value/header/
   type/length). Verify vs oracle (dbdata.test section 1.x).
4. Tests: `go run ./tools/tcl2go/ dbdata` (already exists as a package) —
   confirm green; oracle transcripts under `.agents/dbdata_oracle/`.

## Gates
