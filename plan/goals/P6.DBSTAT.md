# P6.DBSTAT — `dbstat` virtual table (no NoopModule)

## Objective
Implement the SQLite `dbstat` virtual table module (src/dbstat.c) in frigolite
so `dbstat` is no longer registered as `NoopModule`. Reports one row per b-tree
page of every table/index in the database:
`(name, path, rootpage, pageno, pagetype, ncell, payload, unused, mx_payload,
 pgoffset, pgsize)`.

## Context
- `internal/vtab/vtab.go` registers `dbstat` as `&NoopModule{}` (line ~120).
  No implementation exists anywhere (grep-confirmed).
- Closely related to `sqlite_dbpage` (already implemented): both walk the
  database page tree. `dbstat` needs a `PageSource` (same provider dbpage uses)
  plus schema enumeration (iterate `sqlite_schema` for rootpages).
- Depends on the **`vtab.Database` interface** (slice 1 of P6.RTREE) only for
  schema enumeration (`SELECT name, rootpage FROM sqlite_schema`), not for
  shadow tables.
- Source of truth: `../sqlite/src/dbstat.c`; oracle `/usr/bin/sqlite3`.

## Design (SOLID)
- `internal/vtab/dbstat.go` — `DBStatModule` (constructor takes
  `PageSourceProvider`), `DBStatVTab`, `DBStatCursor`. Columns as above.
  `BestIndex` = full scan. `Open` enumerates objects, then does a recursive
  depth-first walk of each b-tree from its rootpage (like dbpage's page reader),
  emitting one row per page with computed stats (ncell, payload sum, unused
  bytes, max payload, page offset, page size). `pagetype` ∈ {leaf, internal,
  overflow}.

## Slices
1. Skeleton: `NewDBStatModule(provider)`, register in `internal/exec/engine.go`
   replacing the `dbstat` Noop. Smoke: `CREATE VIRTUAL TABLE t1 USING dbstat`
   succeeds; columns correct.
2. Page walk: enumerate `sqlite_schema` rootpages; DFS each b-tree; emit pageno/
   pagetype/rootpage/name/path. Verify vs oracle.
3. Stats: ncell, payload, unused, mx_payload, pgoffset, pgsize per page. Verify
   vs oracle (dbstat.test 1.x/2.x).
4. Tests: `go run ./tools/tcl2go/ dbstat` (package exists); confirm green;
   oracle transcripts under `.agents/dbstat_oracle/`.

## Gates

- Pure-Go pre-test + oracle before testgen.
- Final verify: `go test -tags testgen ./testgen/dbstat/ -count=1`.
