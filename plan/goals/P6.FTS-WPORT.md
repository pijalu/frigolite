3. Continuation restore: on merge continuation, rebuild parent interior
   layer buffers by walking the interior block chain from the segdir root
   blob (port `fts3IncrmergeLoad` 4259–4411 exactly — geometry-based
   reconstruction from segdir IS SQLite's approach; keep it, but every
   branch must now match the C dispatch, including the no-op paths from
   lesson §61/§62 hint matrix).

**Evidence / final root causes** (see lessons §WPORT closeout):

## 6. Risks / fallbacks

- **Decoder disagreement with reality** → the decoder was ported wrong:
  re-read the C function, fix decoder. NEVER "fix" a fixture.
- **Per-block parity achieved but e2e still red** → there is a second,
  SQL-level consumer of the layout (e.g., integrity-check); localize with
  the same harness on a narrowed scenario.
- **Small green scenarios regress during T3** → the port broke a path the
  old re-derivation handled; bisect per step (T3 is ordered so each step
  is independently revertable).
- **Fixture DB unreadable by frigolite** → that is itself a bug worth a
  unit test (oracle files must be readable); fix storage, not the fixture.
