## Resolution notes (2026-08-28)

### lock3 path canonicalization (engine)
- Oracle resolves `./tempdir/t1//t2/./t3//./../..//./../../tempdir/..//test.db//`
  to `<cwd>/test.db` via the VFS xFullPathname hook (os_unix.c
  `unixFullPathname`/`appendOnePathElement`, L6983/L7007): `.`/`..`, duplicate
  and trailing slashes collapse lexically BEFORE open(2). Go's os.OpenFile
  passes the raw path → ENOTDIR once test.db exists.
- Fix: `pager.Open` canonicalizes with `filepath.Clean` (lexical equivalent;
  no readlink, matching SQLite's no-symlink fallback). Verified against
  `/usr/bin/sqlite3` (PRAGMA database_list shows resolved path).

### lock3 cross-connection lock matrix (engine)
SQLite pager lock model (src/pager.c sqlite3PagerSharedLock + os_unix.c
unixFileLock): RESERVED (BEGIN IMMEDIATE / open write tx) blocks other
writers only; EXCLUSIVE (BEGIN EXCLUSIVE) blocks readers AND writers.
Frigolite already records these in internal/lockreg (writeTx, exclusive)
but only consulted them for backup. Add execEntry gate:
- write stmt (INSERT/UPDATE/DELETE/DDL): fail "database is locked" when
  another connection holds writeTx OR exclusive on the target file.
- read stmt (SELECT): fail "database is locked" when another connection
  holds exclusive on the target file.
Target file = statement's schema qualifier (default main), keyed via
existing lockKey (in-memory DBs are per-connection, never shared).


### lock2 PENDING lock + testfixture emulation
lock2 models two processes via `launch_testfixture`; the transpiler emulates
the subprocess as a second in-process connection (lockreg is process-local,
keyed by canonical file path — same observable lock matrix).

Pager lock states (src/pager.c LOCKTAB / sqlite3PagerSharedLock):
SHARED < RESERVED < PENDING < EXCLUSIVE. A writer's COMMIT must upgrade to
EXCLUSIVE; readers (SHARED) block the upgrade: COMMIT fails "database is
locked", the transaction STAYS OPEN, and the pager sits in PENDING — new
SHARED requests are denied until the writer releases (lock2-1.5/1.7/1.8).

Engine changes:
- lockreg: add sharedTx (transaction-level SHARED: BEGIN + first read holds
  it until COMMIT/ROLLBACK) and pending marks; ClearConn clears both.
- execSelect-in-transaction registers sharedTx; execCommit/execRollback/
  ClearConn release it.
- execCommit with a write tx: SharedTxByOther or ReadTxByOther ->
  "database is locked" + set pending, transaction stays open.
- CrossConnLockError read gate also fails on pending-by-other.
- Successful COMMIT / ROLLBACK clears pending.

Transpiler changes (tools/tcl2go):
- `testfixture $VAR {SCRIPT}`: sub-transpile SCRIPT with the "db" command
  bound to a dedicated connection var (_tfdbN). `sqlite3 db FILE` opens it,
  `db eval`/`db close`/`catch` operate on it. The do_test result value is
  the script's last command result (catch msg pattern -> msg).
