### Engine implementation

- New `internal/execquery/skipscan.go` (464 lines) implements the skip-scan
  planner strategy mirroring `src/where.c:3517-3554` (WHERE_SKIPSCAN branch):
  - `trySkipScanPlan` is the entry point, invoked from
    `internal/execquery/explain_plan.go::planSingleTable` before the regular
    `bestIndexForQuery` SEARCH/SCAN path.
  - `skipScanForColumns` / `skipScanForColumnsWithStatName` examine each
    candidate index on the table, picking mode 1 (basic K unconstrained
    leading cols) or mode 2 (constrained-leading + unconstrained-middle +
    constrained-trailing, added 2014-08-20 for `a=1 AND c=32`).
  - `formatSkipScanConditions` renders the EQP `(ANY(c0) AND ANY(c1) AND c2=?)`
    string for `EXPLAIN QUERY PLAN` output.
  - `constrainedColumnNames` / `constrainedColOps` collect the
    column-to-constant WHERE predicates, recursing into AND/OR/Paren/Unary
    but treating UnaryOp (`+a`) as no-op (matches `skipscan3.test 1.2`).
  - `stat1Tokens` reads the `sqlite_stat1` row for the given index, skipping
    `noskipscan` and `sz=N` keyword tokens.
  - `withoutRowidPKCols` / `primaryKeyStatName` / `autoindexColumns` handle
    the implicit `PRIMARY KEY` index of a WITHOUT ROWID table (e.g. t1 in
    `skipscan6.test`) and `sqlite_autoindex_*` entries.
  - Cost comparison: skip-scan only fires when `estRows < regularEst`
    (= `stat[nSkip]`) matching SQLite's `whereLoopInsert` winner-take-all.

- `internal/execquery/explain_index.go`:
  - `findIndexOnColsForQuery` now includes the implicit `PRIMARY KEY` index
    of a WITHOUT ROWID table (the schema's IPK has no separate index entry).
  - `indexUsingLabel` consults `selectOutputCols(s)` for covering-index
    detection (covering when index covers SELECT's output columns).
  - `joinNodeFor` / `joinScanNode` invoke skip-scan on join tables.

- `internal/exec/pragma_analyze.go::computeIndexStat` consults
  `Engine.selectEngine.AutoindexColumnsForAnalyze` so autoindex entries
  (sqlite_autoindex_*) get stat-derived sizes instead of the row-count
  fallback.

- `internal/execquery/context.go::SelectContext` gets `SkipScanEnabled()`
  for the runtime toggle.

- New `PRAGMA skip_scan = 0|1` (engine + handler in
  `internal/execpragma/execpragma.go`) toggles the flag. Default ON.

- `internal/exec/engine.go::Engine.SkipScanEnabled` /
  `SetSkipScanEnabled` accessors + `internal/exec/pragma_state.go` Getters.

### Transpiler

- New handler `tools/tcl2go/processcmdextra.go::processOptimizationControl`
  maps TCL `optimization_control db skip-scan {on|off}` /
  `optimization_control db all {on|off}` to `PRAGMA skip_scan = 0|1`.
  Other optimization flags (query-flattener, push-down, transitive, etc.)
  emit a no-op comment.
- `tools/tcl2go/strings.go::regexPatternExpr` strips paired `{`/`}` from
  the inner regex pattern when the result-pattern starts/ends with braces.
  TCL ARE silently treats `{SCAN t9a}` as literal (malformed quantifier
  is dropped); Go RE2 throws on `{`. Mirrors TCL semantics.
- Harness matcher (`frigolite_harness_test.go::matchExpectation` and
  `globMatch`) handles `*GLOB*` patterns (string match, not regex) and
  the `~/REGEX/` / `/REGEX/` paths from TCL `do_test`.
