## Required engine work

### 1. Pager: rollback journal file machinery (`internal/pager/journal.go`)

**Journal file format** (pager.c writeJournalHdr + aJournalMagic):
- Magic: 8 bytes `0xd9, 0xd5, 0x05, 0xf9, 0x20, 0xa1, 0x63, 0xd7`
- nRec:   4 bytes (0xffffffff for nRec+offset-pointer-based recovery, or actual count)
- cksum:  4 bytes (random init for the per-page checksum chain)
- dbSize: 4 bytes (initial db size in pages)
- sector: 4 bytes (sector size for header alignment)
- pgSize: 4 bytes (page size)
- Page records: 4 bytes page number + pageSize bytes page data + 8 bytes checksum

Per-page checksum is `WalChecksumBytes`-like; SQLite's is `sqlite3PagerCksum` which
chains a `crc32c`-style hash with the random init. For frigolite we can mirror
`internal/pager/wal.go`'s `walChecksum` approach (little-endian, fibonacci-weighted).

**Lifecycle** (pager.c `pager_open_journal`, `pager_end_transaction`,
`pager_playback`):
- **Open**: detect existing `test.db-journal` at open time → if so, run
  recovery (read journal header + page records, apply before-images).
- **BEGIN (first write)**: open `test.db-journal`, write header, write
  before-images of dirty pages as they're written.
- **COMMIT**: write the database pages, then handle journal per mode:
  - DELETE: unlink journal
  - TRUNCATE: truncate journal to 0
  - PERSIST: keep journal, truncate to `journal_size_limit`
  - MEMORY: discard in-memory journal (no file)
  - OFF: no journal at all
- **ROLLBACK**: read journal, restore before-images, unlink journal.

### 2. Pager: file permission preservation

When creating `test.db-journal`, copy the main file's Unix mode bits
(unix only — Windows has no mode bits). Use `os.Chmod` after `os.OpenFile`.

### 3. VFS injection layer (`internal/pager/vfshook.go`)

A test-only VFS shim that intercepts xOpen/xClose/xDelete events. Stored as
a list of hook callbacks, fired when the pager opens/closes/deletes a
sidecar file. Used by `internal/exec/testvfs.go` to expose the
`testvfs/filter/script` TCL commands.

### 4. TCL harness emulation

Add the following commands in `internal/exec` so the testgen packages can
emit them:
- `forcedelete PATH` — unlink file (ignore missing)
- `forcecopy SRC DST` — copy file (overwrite)
- `copy_file SRC DST` — copy file (sqlite3_tester's alias)
- `delete_file PATH` — unlink file (Tcl's `file delete`)
- `file attributes PATH -permissions N` — set Unix mode bits
- `file attributes PATH -permissions` — read Unix mode bits
- `file attr PATH -perm` — read Unix mode bits (Tcl test alias)
- `file exists PATH` — true if file exists
- `file size PATH` — file size in bytes
- `atomic_batch_write PATH` — always 0 (we don't have a batched VFS)

These belong in `internal/vtab` or a new `internal/tesharness` package;
they're called from the transpiled test code via helpers.
