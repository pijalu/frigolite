## Strategy (smallest diff, no simplifications)
1. **Quota glob helper**: port `quotaStrglob` from `src/test_quota.c:254-309` to Go
   in `tools/tcl2go/helpers_template_part*.go` as `tclQuotaGlob`. Add
   transpiler handlers for all `sqlite3_quota_*` TCL commands.
   → Makes testgen/quota_glob pass with full coverage.

2. **max_page_count** (engine): add to `EngineState` interface:
   - `MaxPageCount(schema, value string) *Result` — getter/setter; setter clamps
     to `min(N, current_page_count)` per `src/pragma.c:1720`.
   - Pager-level enforcement: at every page allocation point in
     `internal/pager/pager.go` (AcquirePage or equivalent), check
     `pager.maxPageCount` and return SQLITE_FULL ("database or disk is full").
   - Test harness: native + tkt2686.

3. **PRAGMA edge cases (pragma*.test)**: triage per package.
   - Most PRAGMAs already work; failures surface as either:
     (a) missing handlers in `internal/execpragma/pragmaHandlers`,
     (b) handler regressions (secure_delete, journal_mode, etc.),
     (c) transpiler gaps for `pragma` TCL syntax.
   - Process one package at a time: build, run, fix, commit.

4. **Quota VFS (quota / quota2)**: implement a pure-Go `internal/quota`
   package that mirrors `ext/misc/quota.c` semantics:
   - File-size tracker keyed by filename, glob pattern, current total
   - On `Open()` and write growth, check against cap; if exceeded, invoke
     callback; if callback allows, continue; else return SQLITE_FULL.
   - All `sqlite3_quota_*` test commands handled in helpers + transpiler.
