   compact image back over main.
   Implementation plan (frigolite_vacuum.go + parser):
   - parser: capture the INTO target (rule 251) into VacuumStmt.Into [DONE].
   - VACUUM INTO / plain VACUUM via a logical rebuild:
     ATTACH an in-memory vacuum_db in the same engine, re-create the
     schema there (schema-qualified rewrite of the stored CREATE text),
     INSERT..SELECT per table, copy view/trigger/rootpage-0 schema rows,
     preserve user_version/application_id, bump the schema cookie, then
     backup vacuum_db → main (existing Backup machinery) and DETACH.
   - Transaction guard: engine.InTransaction() check [DONE].

   the EXPECTED argument contains a bracketed expression; the comparison
   must evaluate it at runtime (tclExprWith/tclHexioReadInt composition).
4. **Engine: page_size on VACUUM** (vacuum3): VACUUM applies a pending
   PRAGMA page_size change to the rebuilt database.
5. vacuum-into 7xx: PRAGMA schema_version/counter introspection shapes.
