# Archived Plans

These are the original phase plans from before the 2026-07-29 plan rewrite.
They are preserved for historical reference but have been superseded by the
new plans (PLAN-00 through PLAN-10).

Key differences from the new plan:
- Old plans treated failures as individual engine bugs.
- New plan identifies the test infrastructure (P0) as the root complexity.
- Old plans didn't address C API recreation (P7) or test conversion lossiness.
- New plan uses token-level ALTER TABLE processing (P3) matching SQLite's approach.
